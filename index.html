Nudibranch

A self-hosted music library manager & player, with an app for iPhone, iPad and Mac.

TLDR; Nudibranch is split into two parts, a server that manages your library and downloads, and a client application for controlling the server and playing music.
Your music, playlists and podcasts live on a server you run in Docker, and the app or web client connect to the server via an API.
To get started visit the guide here

What you can do with Nudibranch

  • Browse and play your personal music library and podcasts
  • Request and approve new music, and automatically download lossless files via SoulSeek or YTDLP
  • Optional Jellyfin server integration for music and playlists
  • Granular permissions for users so you don't have to give full access to let people play music
  • Manual approval for changes, with automatic backups and library management tools
  • Custom automations for a wide variety of tasks, triggered by IOS shortcuts, webhooks, cron, or manually
  • Robust Siri and IOS shortcuts integration
  • Offline playback and automatic downloads for music and podcasts on the IOS app

How it's set up

The server runs in a 2 to 3 container Docker stack with the API, Web UI, (optional) and SLSKD for downloading music. The Nudibranch API handles finding music, tagging it, staging it, importing it, and routine maintenance. The Web UI provides an easy to access interface for managing your library and playing music. SLSKD interacts with the SoulSeek network to provide music downloads. (Nudibranch and it's developers do not condone piracy. Only share and download music you own.)
The app connects to the server via the API, and can be remotely triggered and sent notifications through the APNS proxy provided by the developer.

Any questions? Check the FAQ — a full install guide is being written.

Getting it

The server is open source and available on GitHub under the GPLv3 license. Two Docker images are available for the API and Web UI, nudibranch-api and nudibranch-web. The iOS/Mac app being developed and will be available on the App Store.

What is a Nudibranch?

Nudibranchs (/'nju:dɪbræŋk/) are soft-bodied marine gastropod molluscs of the order Nudibranchia, commonly known as sea slugs. The program is named after Glaucus atlanticus, a nudibranch whose jelly-like cerata are arranged along its back like wings or fins.
The name was chosen both because the program was designed with Jellyfin in mind and because the animal is my favourite.
