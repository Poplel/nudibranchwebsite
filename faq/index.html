Nudibranch — FAQ

FAQ

Short answers to common questions.

The basics

What is Nudibranch, exactly?

A self-hosted music library manager and player with support for podcasts. Nudibranch is split into two parts: the server, and the client. The server can run without a client, but the client needs the server to function. You can use the ios app or web client to access your server.

Do I need Jellyfin?

No! Jellyfin is entirely optional. Nudibranch can run as a standalone music library manager and player. If Jellyfin is connected and users are paired to their jellyfin counterparts, there are additional features.

Is it free?

The server is open source and free, on GitHub. There are costs associated with running the server yourself, but the software itself is free to use.

What does it run on?

Nudibranch runs in x86 Docker. You can run it on any computer, VPS, or VM that has an x86 processor and Docker installed. ARM support is planned in the near future for Raspberry Pi and similar devices.

The app

Where do I get the app?

The app is not finished yet, but will be in the app store once it's ready. A link to the app store will be posted when it's available.

Is there an Android version?

Not yet! The app is currently only available for iOS devices, however the Web UI is mobile friendly.

Does playback work offline?

Offline playback is available on the Mac and iOS apps, but not on the Web UI. You can play music over your local network without an internet connection.

How do I set up Nudibranch?

Visit the install guide for instructions.

Privacy and notifications

What data do you collect?

None. You host your own server, and no data is sent to any third parties.

How do push notifications work?

The iOS app registers with a small relay run by the developer; your server signs a notification, the relay hands it to Apple, Apple delivers it to your device. The relay never sees any information other than the origin of the request and the type of notification being sent to help catch errors.

If you prefer not to use the relay, you can turn off notifications.

Does my server need to be exposed to the internet?

Technically, no. You will not be able to access your server from outside your local network, and downloads and many tools will not be possible. An Internet connection is highly recommended.

Libraries and users

Where does the music come from?

Your own personal library, or downloaded from sources like SoulSeek or YouTube. (Nudibranch and it's developers do not condone piracy. Only share and download music you own.)

Will it reorganiseor edit my existing files?

Yes if you import them into your library, they will be sorted and updated. This will not happen without explicit instruction.

Can other people use my server?

Yes! Nudibranch supports multiple users with individual permissions. You can give someone the ability to listen and request music without giving them the ability to approve downloads or run maintenance tools.

Can I automate things?

Yes. Automations are trigger → action → notify: fire on a schedule, an interval, a webhook, an iOS Shortcut, or an event
